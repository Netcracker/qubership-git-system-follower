# Gear Lifecycle

## Migration
[Migration](migration.md) procedures between different gear types (Simple -> Complex) and (Complex -> Simple). 

## Update
[Updates](update.md) are managed within different gear types (Simple -> Simple) and (Complex -> Complex). 

## Rollback
[Rollback](rollback.md) involves reverting a component to an older version than the one currently installed.

Please Note:-

- GSF treats install operation as **update** only when it's done between gears of same type.
- GSF treats install operation as **migration** when gear types are different.
